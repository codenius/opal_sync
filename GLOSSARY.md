# OPAL Sync

This context syncs course materials from OPAL to a local folder.

## Language

**Wicket action**:
An operation offered by an OPAL page through its Wicket interface. Some file
downloads require the client to perform this action before it can retrieve the
file.

**Fibercode handoff**:
The file-delivery step in which an OPAL Wicket response directs the client to a
Fibercode URL.

**OPAL session**:
The authenticated context that permits access to a user's OPAL courses and
course materials.

**Recent download**:
The latest successful local download of a course file. A later successful
download of the same file makes it recent again.
